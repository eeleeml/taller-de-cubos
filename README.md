# Taller de cubos

Simulador gratuito para practicar ejercicios psicotécnicos de rotación de figuras de cubos.

- Construye una figura nivel a nivel en una cuadrícula (hasta 6×6×6).
- Gírala en 3D arrastrando o con giros de 90° sobre cada eje.
- Construye una segunda figura y comprueba si es la primera girada, su imagen en espejo o una figura distinta.

Es una sola página HTML sin servidor ni base de datos. Cada persona guarda su última figura en su propio navegador.

## Uso

Abre la web publicada en GitHub Pages, o abre `index.html` directamente en el navegador.

## Tecnología

- HTML, CSS y JavaScript en un único archivo.
- [three.js](https://threejs.org/) r128, cargado desde cdnjs.
